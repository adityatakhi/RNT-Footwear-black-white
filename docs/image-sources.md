# Product image sources

## User-provided RNT images

The original JPEG files shared for this storefront are stored in `public/campaigns/` and displayed without cropping, grayscale, blend modes, or image filters. The product cards link to the four RNT model posters; the homepage gallery shows all eight images.

Product model names, colourways, and listed prices are taken from the relevant poster artwork. Size availability and stock were not included in those images and must be confirmed before enabling ordering.
